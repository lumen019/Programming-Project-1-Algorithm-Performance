1. Project Overview & Objectives
What the application does and its main goal.
This project will implement multiple sorting algorithms, generate input data systematically, measure performance using a consistent metric. We will draw comparisons and decide which is better.

2. Core Features (In Scope)
Every functional feature in the program.
Heap sort, Merge sort, Quick sort, and Shaker sort are the main sort used. These will take the data and let us drive comparisons on which one will work better.

3. Out-of-Scope Items
Explicitly state what will NOT be included to manage workload and avoid scope creep.
Multiple Languages are not included we are only using Java. We are using these main sorts and not others. We are having an array generator, having a driver program, and lastly it will use n= 4,6,8 as the numbers so it isn’t a lot of crazy stuff.

4. Technical Constraints & Deliverables
- Language/Framework: Java
- Platform/Environment: Cross-platform
- Deliverables: Github (obviously)
